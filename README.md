# 📚 ИИ-Ассистент для конспектирования научных статей

Нейроассистент, который помогает быстро и грамотно анализировать научные статьи, выделять ключевые тезисы, структурировать материал и формировать вопросы для самопроверки.

## 🎯 Основные возможности
- **Строгий системный промпт:** Защита от галлюцинаций (ассистент использует только предоставленный текст).
- **Поддержка разных типов статей:** Адаптация под экспериментальные, обзорные и теоретические работы.
- **Десктопный интерфейс:** Удобный веб-интерфейс на базе Streamlit.
- **Telegram-бот:** Возможность конспектировать статьи прямо в мессенджере.
- **Поддержка PDF:** Бот автоматически извлекает текст из загруженных PDF-файлов.

## 🛠️ Технологический стек
- **Язык:** Python 3.10+
- **ИИ-ядро:** OpenAI API (модель `gpt-4o-mini`, Temperature = 0.1)
- **Веб-интерфейс:** Streamlit
- **Telegram-бот:** aiogram 3.x
- **Парсинг PDF:** PyMuPDF (fitz)

## 🚀 Как запустить локально

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/ВАШ_НИКНЕЙМ/research-ai-assistant.git
   cd research-ai-assistant

2.  Создайте и активируйте виртуальное окружение:

   python -m venv venv
# Для Windows:
.\venv\Scripts\activate
# Для Mac/Linux:
source venv/bin/activate
3. Установите зависимости:
    pip install -r requirements.txt 
4. Настройте переменные окружения:
    Создайте в корне проекта файл .env и добавьте в него ваши ключи:
        OPENAI_API_KEY=ваш_ключ_openai
        TELEGRAM_BOT_TOKEN=ваш_токен_телеграм_бота
5. Запустите веб-интерфейс:
    python src/bot.py


## 📂 Структура проекта

    data/ — база знаний в формате CSV (knowledge_base.csv)

    docs/ — документация и инструкции

    prompts/ — системный промпт и few-shot примеры

    src/core.py — ядро для работы с API OpenAI

    src/app.py — интерфейс Streamlit

    src/bot.py — Telegram-бот
